# XhaMil Chat AI

本仓库是 XhaMil 的**自托管服务端与管理后台**：提供即时通讯所需的 HTTP / WebSocket API，以及运营配置界面。消息、媒体与账号数据部署在你自己的机器上；配套 App、桌面端在登录页填写服务器地址即可接入。

基于 Node.js（Express）与 Vue 3 管理端构建。完整聊天体验需配合 Android / 桌面客户端。

---

## 项目介绍

面向希望自行部署 IM 后端的开发者与运维：对接 MySQL（及可选 Redis）后，即可对外提供注册登录、好友与群聊、媒体上传、实时通道与运营后台。客户端填写你的 API 根地址，不绑定固定公网域名。

**核心能力：**

- **账号与鉴权**：注册 / 登录、会话管理；短信 / 邮箱验证码（按配置启用）
- **即时消息**：私聊与群聊；文本、图片、语音、文件等；WebSocket 实时通道
- **群聊 AI**：群内 AI 助手，支持自定义人格 / 系统提示，可按群分配（后台配置）
- **社交与群组**：好友申请、群管理、群公告、@ 提醒等
- **媒体与运营资源**：上传与静态资源；贴纸、头像框等
- **音视频相关**：通话信令与会话能力（媒体通道以客户端为准）
- **运营后台**：用户 / 群 / 媒体 / 功能开关 / 品牌与更新配置
- **可扩展集成**：短信、邮件、人机验证、语音识别 / TTS、地点检索等（Key 仅存服务端）

## 仓库结构

| 目录 | 说明 |
| --- | --- |
| `backend/` | Node.js API、WebSocket、业务逻辑与生产态管理端静态资源 |

## 技术栈

### 服务端 / 管理端

| 类别 | 技术 |
| --- | --- |
| 运行时 | Node.js 18+（推荐 20 LTS） |
| HTTP API | Express |
| 实时通信 | WebSocket（`ws`） |
| 数据存储 | MySQL 8.x（`mysql2`） |
| 缓存（可选） | Redis |
| 媒体处理 | Multer、Sharp 等 |
| 管理后台 | Vue 3、Vite、TypeScript |
| 包管理 | npm（backend）；pnpm / npm（admin-art） |

### 桌面端（开发中）

与本服务端共用同一套后端 API。桌面端界面仍在开发，技术选型如下：

| 类别 | 技术 |
| --- | --- |
| 壳层 | Tauri 2（亦可 Electron 构建） |
| 界面 | Vue 3、TypeScript、Vite |
| UI | Naive UI |
| 状态管理 | Pinia |

Android App 同属配套客户端，登录页支持填写自建服务器地址。

## 快速开始（本地）

```bash
git clone https://github.com/xiongxinx57-bot/XhaMil-Chat-AI.git
cd XhaMil-Chat-AI

# 1. 生成本地配置（勿将真实配置提交到 Git）
cp json/config.example.json json/config.json
# 编辑 json/config.json：数据库、管理员口令、publicSiteUrl 等

# 2. 启动 API
cd backend
npm install
npm start
```

默认监听地址与端口以 `json/config.json` 中 `server` 字段为准（示例配置多为 `0.0.0.0:5000`）。

### 管理后台（开发）

```bash
cd admin-art
cp .env.example .env
cp .env.development.example .env.development
pnpm install   # 或 npm install
pnpm dev
```

### 管理后台（生产构建）

构建产物输出至 `backend/public/admin`，建议与 API 同域部署：

```bash
cd backend
npm run build:admin
```

生产环境完整步骤见：**[docs/DEPLOY.md](docs/DEPLOY.md)**。

## 配置约定

- 仓库仅提供 `json/config.example.json` 作为模板。
- 真实 `json/config.json`、`.env`、密钥、用户媒体与会话数据已由 `.gitignore` 排除，**请勿提交**。
- 短信、邮件、地图、ASR / TTS、大模型等凭据一律保存在服务端配置中，不要写入客户端。

---

## 连接自建服务器

服务端部署完成后，在客户端**登录页**填写你自己的服务器地址即可，无需改代码、无需重新打包。

| 端 | 说明 |
| --- | --- |
| Android App | 登录页可更换服务器地址 |
| 桌面端 | 登录页同样可更换服务器地址（桌面端功能开发中） |

填写站点根地址（不要带 `/api`）。例如：`https://chat.example.com`。更换服务器后需重新登录。
